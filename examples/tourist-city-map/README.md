# Tourist City Map Example

This example demonstrates using VoiceGIS for a consumer-facing tourist app.

## Key Features Showcased:
1. **Dynamic Custom Markers**: Coloring markers based on feature category.
2. **Category Filtering**: `app.registerCommand()` to intercept "show me restaurants".
3. **Bounding Box Navigation**: Automatically fitting the map view to the filtered results.

## How to run
1. Start the Vite dev server from the project root: `npm run dev`
2. Navigate to `http://localhost:5173/examples/tourist-city-map/index.html`

## Try saying:

- *"Show me museums"*
